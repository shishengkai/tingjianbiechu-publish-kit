# v0.1 范围与成功标准

版本 **0.1.0**。本程序将替代 brain 内 agent skill；skill 在程序可用后废弃。

## 做什么

输入一个 **已完成的 MagicDub 任务目录**（默认 `~/Movies/MagicDub/cli/<task>/`，含 `state.json` 与 `exports/final.mp4` + `final.srt`），一条命令产出：

- 发布文案 TXT（含固定落款 `MagicDub 魔法配音，非本人中文发言。`）
- 三张 PNG：视频首帧（成片实际显示尺寸）、列表竖版 1080×1440、列表横版 1440×1080
- provenance：`provenance/tingjianbiechu-publish-kit/<stem>/vN/record.json`

质检：

- **OCR 硬闸**：封面可读文字与 `cover_title` 一致（允许换行），否则重生，**最多 2 次**
- **软闸**（开发期用更强 VL）：人物／多余小字／挡脸等；不过仍可落盘并标 `needs_human_review`
- 生图默认 **不** 开启厂商 `prompt_extend`；封面中文仍不合格时可升级到配置中的 `image_upgrade` 模型（需另备 OpenRouter 等凭据，v0.1 先写配置）

## 明确不做（v0.1）

原声无译制特例、仅改文案／单张封面局部更新 CLI、嵌入视频首帧、代发抖音、多账号／跨平台、全厂商模型矩阵。

## 成功标准与退出码

| 条件 | `record.status` / 标记 | 进程退出码 |
| --- | --- | --- |
| 文案 + 三封面落盘，三张 OCR 过，软闸过 | `delivered` | `0` |
| 落盘成功，OCR 过，软闸未过或跳过争议 | `delivered` + `needs_human_review` | `1` |
| 无法交付（定位失败、OCR 用尽仍不过、API／IO 错误等） | `failed` 或仅 stderr | `2` |

文件尺寸／哈希校验通过 ≠ 平台发布成功。

## 样例根目录

本地 MagicDub CLI 输出：`~/Movies/MagicDub/cli/`（每子目录一个任务）。
