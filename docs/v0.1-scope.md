# v0.1 范围与成功标准

版本 **0.1.0**。本程序将替代 brain 内 agent skill；skill 在程序可用后废弃。

## 做什么

输入一个 **已完成的 MagicDub 任务目录**（默认 `~/Movies/MagicDub/cli/<task>/`，含 `state.json` 与 `exports/final.mp4` + `final.srt`），一条命令产出：

- 发布文案 TXT（含固定落款 `MagicDub 魔法配音，非本人中文发言。`）
- 三张 PNG：视频首帧（成片实际显示尺寸）、列表竖版 1080×1440、列表横版 1440×1080
- provenance：`provenance/tingjianbiechu-publish-kit/<stem>/vN/record.json`
- **花费账本**：每次模型调用一条记录；结束时输出各模型本次合计与任务总花费（人民币）

质检：

- **OCR 硬闸**：封面可读文字与 `cover_title` 一致（允许换行），否则重生，**最多 2 次**
- **软闸**（开发期用更强 VL）：人物／多余小字／挡脸等；不过仍可落盘并标 `needs_human_review`
- 生图默认 **不** 开启厂商 `prompt_extend`；封面中文仍不合格时可升级到配置中的 `image_upgrade` 模型（需另备 OpenRouter 等凭据，v0.1 先写配置）

## 模型花费

每次调用模型后立刻记账（见 `config/pricing.yaml` + `tingjianbiechu_publish_kit/costing.py`）：

1. 若响应中带有明确金额字段，优先采用；美元金额 **×7** 记为人民币。
2. 否则按官方价目用 `usage` 计算：
   - **DeepSeek Flash**：区分 cache hit / miss 与 peak／off-peak（UTC 周一至周五 01:00–04:00、06:00–10:00 为高峰；中国法定放假日全天非高峰，日期表见 pricing 配置，来源国务院 2026 放假通知）。
   - **qwen-plus**：按**单次输入 Token 总量**定档（≤128k / ≤256k / ≤1M），区分普通／思考、缓存命中。
   - **qwen-vl-max**：输入／输出／缓存命中 Token（华北 2 原价）。
   - **qwen3.5-ocr**：输入／输出 Token（无缓存折扣）。
   - **qwen-image-3.0-pro**：按 `usage` 的 `*_image_type`（1k／2k）与张数计输入／生成费。
3. 冒烟核查（2026-09-26）：上述模型响应**均无**直接费用字段，仅有 `usage`；因此 v0.1 默认走计算路径。
4. 展示统一人民币，金额保留 **6 位小数**（`¥1.230000`）。任务结束输出：每个模型合计 + 本次任务总合计；明细写入 provenance。

不把限时优惠、资源包抵扣或控制台账单差异写进“已确认账单”；内部保留 `source=response|calculated`。

## 成功标准与退出码

| 条件 | `record.status` / 标记 | 进程退出码 |
| --- | --- | --- |
| 文案 + 三封面落盘，三张 OCR 过，软闸过 | `delivered` | `0` |
| 落盘成功，OCR 过，软闸未过或跳过争议 | `delivered` + `needs_human_review` | `1` |
| 无法交付（定位失败、OCR 用尽仍不过、API／IO 错误等） | `failed` 或仅 stderr | `2` |

文件尺寸／哈希校验通过 ≠ 平台发布成功。花费表随成功或 `needs_human_review` 交付一并输出；硬失败尽量附已产生的部分花费。
